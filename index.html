From one SEC filing to 14 Qwen calls

A walkthrough of a single request: the Barings Private Credit Corporation issuer tender offer (Schedule TO-I/A, accession 0001859919-26-000002). Evidence is built once with no LLM, frozen to disk, then replayed field by field into qwen3-finance on Ollama. The coloured tags mark the five evidence sources and keep the same colour on every diagram.

5 · build_bundle, per field × stage

Evidence legs → one text block

RULES: candidate_facts whose field_hint matches the field allow-list → - hint= value= context=. Ticker adds a live rescan.
GLINER SPANS: Allow-listed labels only, junk role nouns dropped, ≤ 25 lines, with score= and a 220-char context
TEMPORAL SPANS: Date fields only. date= field_cues= window=. Routed for offer_price but gated off.
HYBRID EXCERPTS: Query = field name + definition + cue words → BM25 → RRF → top 4 chunks, ≤ 2,200 chars. No scores shown to the model.
EXCERPT: Field-specific regex patterns over doc_text + excerpts. Used alone, in copy mode.
→ evidence.jsonl
One record per (row, field): stages[] with text, sources, prompt_mode, on_empty, plus rules_direct, gold. Plus manifest.json and routing.json.

Experiment · scripts/probe_mismatch_twostage.py · qwen3-finance

Two-stage retrieval probe: narrow evidence first, broaden only on null

The single-call setup puts every evidence source into one prompt. This probe tested whether Qwen does better when it first sees only the most targeted source, and gets the full set only if it returns null. It re-ran just the cells the single-call run got wrong.

Where the fixes came from. 11 of the 12 date fixes came from Stage A. Seven were the right date found once the hybrid chunks no longer competed. Five were correct blanks, where validate dropped a wrong date or Qwen returned null. Bidder and subject_company were fixed in Stage B, after rules alone returned null. Offer price was fixed by HYBRID alone, the NAV formula wording.

Limit. Only cells that were already wrong were re-run, so this does not measure how many correct cells the two-stage plan would break. It was not adopted. Production routing still makes one call per field.

Why freeze

Retrieval, GLiNER and the temporal tagger run once. Any model (qwen3-finance, gemma, LangExtract) is then scored on the exact same 1,400 evidence cells, so differences come from the model alone.

Noise Qwen has to filter

Every date field in this filing gets the same 20 temporal spans, including "1934" (the Exchange Act) and "2500" (a suite number), all with field_cues=0. That is why the date prompts allow null and why Pass C validate runs.
